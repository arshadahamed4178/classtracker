# 📚 ClassTracker – Student & Tutor Management System

## 📖 Overview
ClassTracker is a web application for managing student and tutor information with structured workflows for registration, record management, tutor assignment, and search. It demonstrates full-stack development using Django with database integration and dynamic templates.

---

## ✨ Features
- Student & tutor registration  
- View, update, and manage records  
- Tutor assignment workflow  
- Search and filter functionality  
- Organized data handling  

---

## 🛠️ Tech Stack
- Backend: Django 4.2, Python  
- Frontend: HTML, CSS, JavaScript, Django Templates  
- Database: SQLite  
- Image Handling: Pillow  

---
