# 📚 ClassTracker – Student & Tutor Management System

## 📖 Overview
ClassTracker is an application for managing student and tutor information with structured workflows for registration, record handling, tutor assignment, and search. It helps organize academic data efficiently through a simple and user-friendly interface.

## ✨ Features
- Student & tutor registration  
- View, update, and manage records  
- Tutor assignment system  
- Search and filter functionality
- Organized data management  

## 🛠️ Tech Stack
- Backend: Django
- Frontend: HTML, CSS, JavaScript
- Database: SQLite
